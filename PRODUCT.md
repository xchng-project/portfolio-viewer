# Product

## Register

product

## Users

DeFi users who connect an EVM wallet to inspect and manage Aave positions across supported mainnet networks. They are usually comparing balances, APY, debt, collateral, and transaction readiness before taking a borrow, repay, supply, or withdraw action.

## Product Purpose

Portfolio Viewer helps users see their active Aave portfolio and execute position-management transactions from one focused interface. Success means the user can quickly confirm the selected network, understand available actions, and submit a transaction with clear feedback.

## Brand Personality

Calm, precise, trustworthy. The interface should feel like a focused financial workstation: dense enough for repeated use, clear enough for high-stakes actions, and restrained enough to keep attention on balances and risk.

## Anti-references

Avoid crypto casino styling, neon overload, glossy glass panels, decorative chart noise, vague marketing copy, and playful transaction states. Do not make the app feel like a landing page when the user is already in a workflow.

## Design Principles

Show operational context before actions.
Make network, wallet, balances, and transaction state visible without forcing the user to hunt.
Use restrained color for selection, primary actions, and status only.
Keep tables dense but readable on desktop and horizontally safe on mobile.
Treat transaction modals as confirmation surfaces with clear inputs, limits, errors, and success feedback.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard focus states, readable disabled states, reduced-motion support, and clear copy for users who rely on screen readers or need to verify financial actions carefully.
